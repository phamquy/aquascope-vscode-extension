# T-071 Prepare and publish the Windows release

Spec: [[specs/features/012-windows-support/spec.md]]

## Done when

- [ ] A new extension version has a Windows VSIX that passes the strict package build and content checks.
- [ ] The Windows VSIX is attached to the matching GitHub release alongside the other supported platform packages.
- [ ] Publishing the release succeeds through the existing Marketplace workflow, and the Windows package is installable from the Marketplace.
