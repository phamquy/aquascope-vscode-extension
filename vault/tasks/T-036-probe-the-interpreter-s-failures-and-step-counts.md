## Notes

- Plan: [[specs/features/007-stack-heap-diagrams/plan.md]]. Extends the spec's 2026-11-07 probe (Appendix A). The Miri-built library can be built into the scratchpad or spike folder with `MIRI_SYSROOT=<folder> cargo +nightly-2026-05-01 miri setup` (14 s); the pinned nightly here already has `miri` and `rust-src`.
- Done on 2026-11-08. `spikes/007-interpreter/probe.sh` builds a Miri standard library into its `work/` folder on first run, then runs each program as `src/main.rs` of a fresh binary crate with spike 002's binaries and trimmed toolchain, in 003's environment plus `MIRI_SYSROOT`, under a 20 s timeout; `report.py` writes `work/report.txt`. The programs are in `spikes/007-interpreter/programs/`, and the loop and recursion programs are generated by the script.
- Failures: a panic, a failed `assert_eq!`, `process::exit` and a read from standard input all return exit 0 with `{"Err": {"type": "BuildError", "range": null}}`, no steps and nothing in stderr. Undefined behaviour (use after free) returns `Ok` with its steps and an error result naming it. Type errors, borrow errors and a missing `main` exit 101 with no output; `cargo check` reports E0308, E0502 and E0601. The endless loop hit the timeout. This matches the plan's classification for T-039, so only D4 needed revising: undefined behaviour is drawn with its steps (new AC11).
- Steps: a `for` loop is one step however many iterations it runs, so loops alone never approach a limit. Calls to the program's own functions multiply steps, about five per call, and each step carries the whole stack: 5,004 steps and 4.1 MB for 1,000 calls, 606 steps and 10.4 MB for recursion 100 deep. D6's limit is set to 100 steps; the fixtures need at most 11. AC10 now uses a function called in a loop.
- Columns in the trace count characters, as in the permissions output, so T-040 must convert them to UTF-16.
- Captured for the tests: `01_move_string`, `05_method_mut_borrow`, `n1_non_ascii`, `i1_panic` and `i4_use_after_free` as `src/test/fixtures/data/*.interp.json`, and `i6_no_main.check.jsonl`; the programs `i1_panic`, `i4_use_after_free` and `i6_no_main` are now in the fixture workspace. `embedInput.test.ts`'s scan of the data folder skips the `*.interp.json` traces.
- Spec revised: D4 and D6 revisions, R5, R7, R8, AC8, AC10, new AC11 and Appendix A; the plan, `tasks.md` and the T-040 and T-041 notes follow.
- `npm run typecheck && npm run lint && npm test`: 100 passing.
