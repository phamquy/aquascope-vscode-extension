# Aquascope embed frontend

Vendored by `scripts/vendor-aquascope-embed.sh`; do not edit. `embed.iife.js` and `style.css` are copied unchanged from the `js/` folder of the published crate mdbook-aquascope 0.4.0 (crates.io archive SHA-256 `ee615a65eb23fdb9cd58c47d35a202469fe220f77c72e3fd2e592bf843f71696`), which was built from Aquascope commit f2d0a06034b86765a91f10b7c8e40ec31ecb87a6 (v0.4.0), https://github.com/cognitive-engineering-lab/aquascope. Aquascope is MIT licensed, copyright (c) 2022 Gavin Gray; `LICENSE` is its licence text at that commit.

`embed.iife.js` is a build that bundles third-party libraries, among them React and ReactDOM (which includes a function derived from Modernizr), CodeMirror 6, lodash, Floating UI, Leader Line, and Font Awesome's SVG core with its free solid icons (code under MIT, icons under CC BY 4.0). Their notices and licence texts are in `THIRD-PARTY-NOTICES`, generated by `scripts/embed-notices.py`.
